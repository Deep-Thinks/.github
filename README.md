## 🌊 关于我们

<p align="center">
  <strong>技术不该是孤岛</strong>
</p>

**Deep-Think** 是一个由厦门本地 AI 爱好者自发组织的**非营利性开源社区**。我们致力于成为全国优质 AI 社区在福建/厦门的落地合作节点，以及厦门本地 AI 人才与产业之间的连接器。

我们与 **Datawhale**、**OpenBMB**、**AGI Bar** 等国内优质 AI 开源社区保持深度交流与合作，为厦门建立一个活跃的 AI 人才社区。

---

## 💡 核心理念

> **平等交流，传递价值，共同成长**

这是 Deep-Think 的核心指导思想。我们相信：

- 🤝 **平等** - 所有成员无论背景、职位高低，都能基于共同的兴趣进行平等的技术探讨
- 📚 **分享** - 鼓励知识的分享与传递，让经验流动起来
- 🌱 **成长** - 让每一位参与者都能在社区中获得成长
- 🚀 **进步** - 共同推动技术的进步

## 🎯 社区使命

### 问题：区域连接效率低

| 痛点 | 现状 |
|------|------|
| 👥 开发者分散 | 福建厦门地区 AI 开发者缺乏连接 |
| 💬 缺乏交流 | 缺少高质量技术交流场景 |
| 🌐 难以落地 | 全国社区难以高效落地本地 |
| 🔗 产业脱节 | 本地产业与技术脱节 |

### 方案：搭建连接平台

我们致力于搭建平台，将这些分散的力量连接起来，促进本地技术生态的繁荣。

## 🎬 社区起源

### 为什么是现在？

过去两年，AI 技术以周为单位迭代。我们见证了：

- 🚀 开源模型的爆发
- 🔄 从"调包侠"到"提示词工程师"的身份转换
- 🌙 在深夜 debugging 时翻遍社区却找不到一个活人交流的孤独

### 厦门的现状

| 优势 | 短板 |
|------|------|
| ✅ 有优秀的开发者 | ❌ 缺少面对面的技术碰撞 |
| ✅ 有丰富的产业场景 | ❌ 缺少 AI 与实体经济的连接者 |
| ✅ 有热情的学习者 | ❌ 缺少共同成长的安全空间 |

**技术不该是孤岛。** 所以我们决定打造一个真正属于开发者的连接器与孵化器。这就是 Deep-Think 社区的由来。

## 🏛️ 社区治理

### 透明机制

社区重大决策遵循以下原则：

| 序号 | 原则 | 说明 |
|------|------|------|
| 1️⃣ | **社区优先原则** | 社区利益高于个人利益 |
| 2️⃣ | **合作伙伴尊重原则** | 尊重所有合作伙伴的价值 |
| 3️⃣ | **长期生态优先原则** | 关注长期生态建设而非短期利益 |
